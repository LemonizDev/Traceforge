# Workflow 11: Comparative Intelligence

## Goal
Compare repositories in the user's workspace to reveal capability differences, architectural patterns, and reusable ideas.

## Comparison dimensions
- Component types and inventories.
- Skills, commands, agents, hooks, and MCP capabilities.
- Workflow structures and delegation patterns.
- Dependency and environment requirements.
- Security findings and policy posture.
- Execution and verification coverage.
- Architecture and complexity metrics.
- Declared capabilities versus observed capabilities.

## Steps
1. Select repositories and specific analysis runs/revisions.
2. Normalize ecosystem-specific concepts into shared capability categories while preserving original types.
3. Align comparable components and workflows.
4. Calculate differences and identify unmatched concepts.
5. Distinguish absent from not detected, unsupported, and unverified.
6. Surface reusable patterns and potential improvements with evidence.
7. Preserve comparison inputs and algorithm version.

## Outputs
Comparison report, side-by-side matrices, graph diffs, reusable-pattern candidates, evidence links.

## Acceptance criteria
- Comparisons are reproducible.
- Different analysis versions are disclosed.
- Similar names alone do not imply equivalent capabilities.
- Missing detection is not reported as confirmed absence.
